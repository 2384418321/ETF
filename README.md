# ETF 趋势闸门

一条均线，两个宽基 ETF，五年里把「买入持有 −23.5%」做成「+29.8%」。

这不是选股策略，是**仓位开关**：站上均线就持有，跌破就空仓，中间不猜。

```
每只 ETF 各自一条 MA20
  收盘 > MA20 × 1.02  →  持有，占 40% 总资产
  收盘 ≤ MA20 × 1.02  →  空仓，现金趴着
第 D 日收盘出信号，第 D+1 日开盘调仓
```

## 为什么是这个形状

A 股宽基的特点是：**涨的时间短，跌的时间长且深**。择时不需要预测顶部，
只需要在跌破均线之后愿意走、并且走得掉。均线在这里不是预测工具，是止损的自动化。

缓冲 2% 是为了压掉噪声带来的来回摩擦——贴着均线反复穿越，是这类规则最大的成本来源。

## 实测

账户级模拟：按股数、现金、手续费撮合，只在信号翻转那天以次日开盘价成交，成交后权重自然漂移。

| 配置 | 2022 | 2023 | 2024 | 2025 | 2026 | 近一年 | 五年累计 | 最大回撤 |
|---|---|---|---|---|---|---|---|---|
| MA20 + 2%，每只 40% | +5.0% | **−1.0%** | +18.2% | +1.3% | +4.4% | +5.6% | **+29.8%** | −10.2% |
| 同上，仓位 ×0.8 | +4.0% | **−0.8%** | +14.5% | +1.0% | +3.5% | +4.5% | +23.6% | **−8.4%** |
| 同上，仓位 ×0.7 | +3.5% | −0.7% | +12.7% | +0.9% | +3.1% | +4.0% | +20.5% | −7.5% |
| 等权买入持有 | −25.3% | −6.6% | +6.6% | +25.2% | −17.8% | −14.1% | −23.5% | −40.3% |

2015 年至今年全样本：规则 +220.5%（回撤 −33.7%），买入持有 +122.5%（回撤 −56.7%）。

## 三个必须知道的事实

**一、2023 是亏的。** 严格按账户模拟，2023 是 −1.0%（×0.8 仓是 −0.8%）。
所以「每年都正」这句话不成立——它是「四年正、一年约等于平的负」。早期用净值序列平均
得到的 +0.2% 是没有扣执行细节的算法，以账户模拟为准。

**二、收益高度集中在 2024。** 五年累计 +29.8% 里，2024 贡献 +18.2%。
剩下四年合起来只有约 +10%。这意味着规则不是每年赚钱，而是「少亏、然后在能赚的年份不缺席」。

**三、大部分时间是空仓的。** 平均仓位约 20%，也就是 80% 的交易日里这个账户什么都不做。
如果你需要「天天有事干」，这套东西会让你很难受。

## 它只能做 ETF 吗

不是。规则本身只要求「一条可交易的连续价格序列」，ETF、指数、个股、商品都能套。

适合 ETF 的原因是另外三条：没有个股暴雷与退市风险、没有涨跌停导致的进出困难、
交易成本低（ETF 免印花税）。把同样的均线套到个股上，个体噪声会让信号质量显著下降；
作者对 A 股日频个股做过的五组独立检验，超额收益全部为负，所以这里不发布个股版本。

## 跑起来

只需要一个带 `etf_daily` 表的 SQLite 数据库：

```sql
-- 表的形状：ts_code, trade_date(YYYYMMDD 字符串), open, high, low, close
select ts_code, trade_date, open, high, low, close from etf_daily where ts_code='510300.SH';
```

```bash
pip install -r requirements.txt
export ETF_DB=/path/to/market.db

python strategy/etf_gate.py                  # 最新交易日的信号与目标股数
python strategy/etf_gate.py --date 20261120 --capital 100000
python backtest/gate_backtest.py             # 账户级回测
python backtest/gate_backtest.py --grid      # 参数网格
python backtest/gate_backtest.py --scale 0.8 # 降杠杆
```

## 参数不是真理

MA20 + 2% 是从一组网格里挑出来的。同一批数据上，MA10+1% 五年只有 +6%，
MA60 之后基本全负，缓冲为 0 时回撤会翻三倍。**参数在样本内是拟合，样本外是赌博。**
改参数之前先想清楚：你是在改规则，还是在改历史。
